# Mentra Flutter Client (`apps/mentra`)

The cross-platform client for **Mentra — AI Study Coach & Focus Intelligence Workspace**.

Built with Flutter 3 and Dart, the application runs on Web, macOS desktop, Windows, and mobile targets. It features a custom Material 3 design system, on-device computer vision focus telemetry, real-time AI study coaching via progressive SSE streaming, rich Markdown note taking, goal tracking, and interactive analytics.

## Key Capabilities

### 1. Dual-Layer Resilient Repositories
Every feature repository implements an `Api*Repository` paired with an optional `fallbackRepository` (e.g. `MockNoteRepository`, `MockGoalRepository`, `MockAnalyticsRepository`):
- When connected to the FastAPI backend, data synchronizes to PostgreSQL.
- When running in an offline environment, demo mode, or when browser HTTPS mixed-content policies block `http://127.0.0.1:8000`, the application automatically delegates queries and mutations to the fallback repository. The user experience is never blocked by infinite spinners or blank screens.

### 2. Five-Stage Study Session Lifecycle
The `SessionController` enforces a strict, reliable state machine:
1. **`idle`**: User sets up session target duration, subject, topic, and monitoring preferences.
2. **`preparing`**: 5-second countdown allowing the user to position their camera, adjust lighting, and state their study intention.
3. **`active`**: Countdown timer, live focus score, elapsed duration, and debounced distraction alerts.
4. **`paused`**: Session time stops; camera hardware is released to preserve privacy and reduce CPU usage.
5. **`completed`**: Prompts the student for post-session qualitative reflection before saving final statistics.

### 3. Privacy-Preserving Focus Monitoring
- Detects face presence with a debounced window to eliminate noise from momentary frame drops.
- Measures Eye Aspect Ratio (EAR) to distinguish natural blinks (<500ms) from sustained eye-closure / drowsiness.
- Video frames exist solely in volatile memory and are discarded immediately after feature computation.

### 4. Real Local LLM AI Coach
- Connects to the local FastAPI backend stream endpoint (`POST /api/v1/ai-coach/stream`) powered by `Qwen2.5-1.5B`.
- Features real Server-Sent Events (SSE) token decoding, displaying words as they are generated by the neural network (~20 tokens/second).
- Multi-turn conversation history is maintained per session.
- User can cancel streaming at any moment with `POST /api/v1/ai-coach/cancel`.

## Local Development

### Prerequisites
- Flutter 3.24+ (`flutter doctor`)
- Chrome browser (for web testing) or macOS desktop developer tools

### Setup Commands
```bash
# Fetch pub dependencies
flutter pub get

# Check static analysis
flutter analyze

# Run unit, widget, and chaos test suites
flutter test

# Run in Chrome with hot reload
flutter run -d chrome

# Run macOS native desktop app
flutter run -d macos
```

---

## Web Production & Netlify Deployment

To generate an optimized web release bundle:
```bash
flutter build web --release --base-href /
```

The output bundle is generated in `build/web/`. A `_redirects` file is included in `web/_redirects` to route all single-page application paths back to `/index.html` with status `200`.

A standalone build script is provided at the repository root:
```bash
bash ./netlify_build.sh
```

## Testing & Quality Assurance

The test suite covers:
- **`cv_monitoring_test.dart`**: Verifies face presence debouncer, drowsiness detector, and distraction cooldown timers.
- **`session_engine_test.dart`**: Tests all state transitions of `SessionController`.
- **`analytics_test.dart`**: Tests analytics overview models, zero-filling, and UI widgets.
- **`ai_coach_test.dart`**: Tests streaming SSE parser and chat rendering.
- **`failure_chaos_test.dart`**: Validates token wipe on 401, socket error resilience, and input edge cases.
- **`widget_test.dart`**: Full end-to-end integration navigation test across onboarding, auth, workspace, notes, goals, and sessions.
